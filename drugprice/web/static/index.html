匯入要查的藥品

可以直接貼上，或選擇檔案。每行一個商品名就可以， 但強烈建議一併提供成分名——各國商品名差異很大， 只靠商品名比對會漏掉很多。

格式一：每行一個商品名

Eliquis
Exforge
Zelboraf

格式二：有表頭的 CSV（建議）

商品名,成分名,ATC,含量,藥商
Eliquis,apixaban,B01AF02,2.5 mg,Bristol-Myers Squibb
Exforge,amlodipine+valsartan,C09DB01,5/80 mg,Novartis

欄位名可用中文或英文，順序不拘。可用的欄位：商品名、成分名、ATC、含量、劑型、藥商。

下載各國藥價

勾選要下載的國家後執行。程式會直接連到各國官方網站取得檔案， 原始檔會原封不動保存在 raw 資料夾並計算雜湊值，作為日後的佐證。

澳洲需要比較久。 澳洲官方 API 規定每 20 秒只能請求一次，且此上限由全世界的使用者共用， 因此澳洲一國約需 2 分鐘。這是官方規定，不是程式慢。
