## 二、本次推翻的兩項舊結論

### 加拿大薩克其萬省其實有官方機讀檔

先前的報告記載「查無官方整批下載，僅有逐筆查詢頁與 PDF」，
以及「站台 robots.txt 擋自動化」。重新查證後，**兩項都不成立**：

**關於 robots.txt**：該站根本沒有這個檔案。
`/robots.txt` 回傳的是單頁應用程式的首頁 HTML，
與任意不存在的路徑（例如 `/nonexistent-xyz`）的回應完全相同，
兩者都是 HTTP 200 加上同一份 HTML。先前應是把 SPA 的萬用路由
誤判為「有 robots.txt 且擋住」。

**關於整批下載**：官網提供
**Drug Plan Formulary in Fixed Width Format**——
固定寬度純文字檔，**並附官方逐欄位版面說明文件**。

| 項目 | 內容 |
|---|---|
| 資料檔 | `https://formulary.drugplan.ehealthsask.ca/Publns/Formularyv62_172fw.txt` |
| 版面說明 | `https://formulary.drugplan.ehealthsask.ca/Publns/FormularyLayout.txt` |
| 大小 | 約 830 KB，10,345 列，其中產品列 6,580 筆 |
| 更新 | 每月，現行為 effective 2026-09-01 |

**為什麼先前會漏掉**：查詢頁是 Vue 單頁應用程式，
下載連結寫在 JavaScript 套件（`FixedWidthFormat.*.js`）裡，
從首頁 HTML 看不到。我是從 JS 套件中找出 `FFWFormat` 與 `FFWLayout`
兩個設定值才取得網址的。

這正好符合專案避雷紀錄那條：瑞典、比利時、德國的「找不到整批下載」
結論後來都被推翻，薩省也是同一回事。**「查無」通常只代表還沒找對地方。**

**可信度也跟著提升**：先前規劃是解析 PDF，並標註「PDF 解析等級、
未經官方逐欄位定義文件驗證」。現在有官方版面說明文件，
可信度與法國、比利時同級。

### 瑞士的整批下載網址已經失效

報告記載的
`https://epl.bag.admin.ch/static/sl/current/excel/publication/YYYY-MM-01/Publications.xlsx`
現在回應 **404**，試過當月與前兩個月都一樣。

BAG 的專科藥品清單網站已改版為 Angular 單頁應用程式
（`sl.bag.admin.ch`），後端 API 為 `epl.bag.admin.ch/api/sl/`，
但**需要驗證才能存取**（回應 401）。從前端程式看得出官方資料
正轉向 FHIR 格式發布（`fhir.ch/ig/ch-epl`、`github.com/bag-epl`）。

因此瑞士由「已完成但欄位待驗證」改列為**人工**，
並附上待辦：洽 BAG 詢問新版整批下載或 FHIR 端點的公開存取方式。

> 這也說明了為什麼報告裡「已測試可下載」的項目需要定期重測。
> 本工具的「連線體檢」按鈕就是為此。

## 三、德國的兩個來源，只有一個有價格

| 來源 | 可整批下載 | 含價格 | 說明 |
|---|---|---|---|
| BfArM Festbeträge | PDF | **是** | 逐筆固定給付額與藥局零售價，約 4 MB，每月 1 日與 15 日更新。網址規律為 `festbetraege-YYYYMMDD.pdf` |
| G-BA AMNOG（AIS） | XML（26.7 MB） | **否** | 效益評估決議，含 PZN、ATC、附加效益結論，但**不含談判後的價格金額** |

已實測 G-BA 的 XML 可以下載（POST 到 `ais.g-ba.de/aktuelle-version`，
再跟隨轉址取檔），但因為**不含價格**，放進藥價表會誤導，
因此本階段不納入為價格來源。

> **另一個考量**：G-BA 的下載表單要求勾選同意使用條款。
> 由程式代為勾選，等於由程式代表單位接受條款。
> 這種同意應該由人來做，所以即使將來實作，也會設計成
> 由使用者在介面上明確勾選後才執行，不預設代勾。
> 官方另有「申請永久自動化存取」的正式管道，長期應走那條路。

## 四、人工待辦清單

介面新增「人工待辦」分頁。對每個無法自動化的國家，列出：

1. **為什麼不能自動化**——寫清楚原因，不是只說「不支援」
2. **操作步驟**——逐步告訴同仁要做什麼
3. **後續處理**——這個國家接下來打算怎麼解決
4. **待查藥品清單**——每個藥品一個可直接點開的查詢網址

查詢網址會依各國查詢頁的格式帶入藥品名，例如瑞士的
`compendium.ch/search?q=Eliquis`，同仁點了就直接看到結果，
不用自己複製貼上。

沒有查詢樣板的國家（如德國 ROTE LISTE）則連到查詢首頁。
